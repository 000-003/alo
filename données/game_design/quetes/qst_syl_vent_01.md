# Le Vent qui ment — `QST_SYL_VENT_01`

## Identification
- **QST_ID** : `QST_SYL_VENT_01`
- **Type** : Amorce fil rouge
- **Donneur** : `NPC_SWI_01` — Devin des Vents
- **Prérequis** : Niveau 10 | Affinité Sylphe ≥ 50
- **Récompense** : 350 EXP, 200 Yrds, prophétie « Le Vent qui ment »

## Déroulement (étapes)
1. Le Devin des Vents perçoit une perturbation dans le courant aérien — les vents ne disent plus la vérité autour de Swilvane.
2. Interroger trois anciens de la cité pour recouper les signes.
3. Revenir vers le Devin : les vents mentent parce que quelqu'un manipule les courants depuis les hautes tours.

## Dialogues (donneur)
- **Début** : « Le vent souffle, mais ses mots sont faux. Quelque chose ou quelqu'un altère les courants au-dessus de nos tours. Écoute les anciens, puis reviens. »
- **Fin** : « Les murmures confirment mes craintes. Une magie interdite tord le ciel. Trouve la source avant que le vent n'oublie comment dire vrai. »

## Notes d'intégration
- Ne jamais résoudre le fil rouge (CDC-QST-01 D43)
