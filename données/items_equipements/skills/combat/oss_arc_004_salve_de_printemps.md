# Salve de Printemps

## Identification Cardinal
- **Skill_ID** : `OSS_ARC_004`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Arc
- **Tier** : T2 · **Rareté** : Rare

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 18 |
| Coût Stamina | 25% de la jauge |
| Nombre de Hits | 3 |
| Multiplicateur Total | ×2.0 |
| Post-Motion Delay | 1.0s (le joueur est vulnérable) |
| Niveau Requis | 11 |
| Déblocage | Maîtrise Confirmé |

## Séquence d'Animation
Trois flèches décorées de pétales de fleurs sont tirées en salve. Chaque flèche laisse une traînée florale derrière elle.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Confirmé
- **Commande** : `!learn_skill OSS_ARC_004` puis `!cast salve_de_printemps` en combat

## Lore (Encyclopédie d'Argo)
Un skill offert par la Déesse du Printemps lors d'un événement saisonnier. Les collectionneurs le recherchent pour son esthétique unique.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_ARC_004')`
