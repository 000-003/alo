# Flétrissure

## Identification Cardinal
- **Skill_ID** : `OSS_RAP_010`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Rapière
- **Tier** : T4 · **Rareté** : Légendaire

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 88 |
| Coût Stamina | 66% de la jauge |
| Nombre de Hits | 9 |
| Multiplicateur Total | ×5.5 |
| Post-Motion Delay | 3.0s (le joueur est vulnérable) |
| Niveau Requis | 42 |
| Déblocage | Maîtrise Avancé + Quête « Le Jardin Fané » |

## Séquence d'Animation
Neuf estocades infligeant une pourpre nécrotique. Chaque toucher laisse une traînée violacée qui flétrit la chair ennemie. Le dernier coup brise l'âme.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Avancé + Quête « Le Jardin Fané »
- **Commande** : `!learn_skill OSS_RAP_010` puis `!cast fletrissure` en combat

## Lore (Encyclopédie d'Argo)
Un skill maudit trouvé dans un donjon oublié. Les PNG guérisseurs refusent de soigner les blessures infligées par cette technique.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_RAP_010')`
