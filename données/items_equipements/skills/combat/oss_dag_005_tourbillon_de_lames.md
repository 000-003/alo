# Tourbillon de Lames

## Identification Cardinal
- **Skill_ID** : `OSS_DAG_005`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Dague
- **Tier** : T2 · **Rareté** : Rare

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 22 |
| Coût Stamina | 30% de la jauge |
| Nombre de Hits | 4 |
| Multiplicateur Total | ×2.4 |
| Post-Motion Delay | 1.0s (le joueur est vulnérable) |
| Niveau Requis | 15 |
| Déblocage | Maîtrise Confirmé |

## Séquence d'Animation
Le joueur tourne sur lui-même en lançant des coups dans toutes les directions. Quatre entailles circulaires tailladent tout ce qui se trouve à portée.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Confirmé
- **Commande** : `!learn_skill OSS_DAG_005` puis `!cast tourbillon_de_lames` en combat

## Lore (Encyclopédie d'Argo)
Une technique de survie utile quand on est encerclé. Les joueurs l'utilisent aussi pour ouvrir les coffres piégés... avec des résultats mitigés.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_DAG_005')`
