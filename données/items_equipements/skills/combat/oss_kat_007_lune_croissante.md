# Lune Croissante

## Identification Cardinal
- **Skill_ID** : `OSS_KAT_007`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Katana
- **Tier** : T3 · **Rareté** : Épique

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 46 |
| Coût Stamina | 46% de la jauge |
| Nombre de Hits | 6 |
| Multiplicateur Total | ×3.3 |
| Post-Motion Delay | 1.8s (le joueur est vulnérable) |
| Niveau Requis | 26 |
| Déblocage | Maîtrise Confirmé + Entraîneur |

## Séquence d'Animation
Un enchaînement de six mouvements en croissant, chaque taille épousant la courbe de la lune. Le final est un grand arc argenté qui fend le ciel nocturne.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Confirmé + Entraîneur
- **Commande** : `!learn_skill OSS_KAT_007` puis `!cast lune_croissante` en combat

## Lore (Encyclopédie d'Argo)
Un skill qui ne peut être appris que les nuits de pleine lune, auprès d'un PNG mystérieux dans les ruines lunaires. Très prisé des collectionneurs.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_KAT_007')`
