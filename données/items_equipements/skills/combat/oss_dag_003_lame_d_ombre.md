# Lame d'Ombre

## Identification Cardinal
- **Skill_ID** : `OSS_DAG_003`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Dague
- **Tier** : T1 · **Rareté** : Commun

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 8 |
| Coût Stamina | 14% de la jauge |
| Nombre de Hits | 2 |
| Multiplicateur Total | ×1.5 |
| Post-Motion Delay | 0.5s (le joueur est vulnérable) |
| Niveau Requis | 4 |
| Déblocage | Maîtrise Novice |

## Séquence d'Animation
Deux coups rapides portés depuis l'ombre. Le premier aveugle, le second tranche. L'attaquant semble disparaître entre les deux frappes.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Novice
- **Commande** : `!learn_skill OSS_DAG_003` puis `!cast lame_d_ombre` en combat

## Lore (Encyclopédie d'Argo)
Un skill basique qui initie les joueurs aux techniques d'infiltration. Les voleurs aguerris le considèrent avec nostalgie.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_DAG_003')`
