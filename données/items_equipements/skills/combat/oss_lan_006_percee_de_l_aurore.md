# Percée de l'Aurore

## Identification Cardinal
- **Skill_ID** : `OSS_LAN_006`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Lance
- **Tier** : T3 · **Rareté** : Épique

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 44 |
| Coût Stamina | 44% de la jauge |
| Nombre de Hits | 5 |
| Multiplicateur Total | ×3.0 |
| Post-Motion Delay | 1.5s (le joueur est vulnérable) |
| Niveau Requis | 24 |
| Déblocage | Maîtrise Confirmé + Entraîneur |

## Séquence d'Animation
Cinq piques lumineuses portées avec une vitesse croissante. La première est une étoile filante, la dernière est une aurore boréale qui transperce tout.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Confirmé + Entraîneur
- **Commande** : `!learn_skill OSS_LAN_006` puis `!cast percee_de_l_aurore` en combat

## Lore (Encyclopédie d'Argo)
Un skill enseigné par les Chevaliers de l'Aube. La légende dit que ce skill peut percer le voile entre les mondes.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_LAN_006')`
