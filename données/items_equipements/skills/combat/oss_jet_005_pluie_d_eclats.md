# Pluie d'Éclats

## Identification Cardinal
- **Skill_ID** : `OSS_JET_005`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Armes de Jet
- **Tier** : T2 · **Rareté** : Rare

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 24 |
| Coût Stamina | 32% de la jauge |
| Nombre de Hits | 4 |
| Multiplicateur Total | ×2.3 |
| Post-Motion Delay | 1.0s (le joueur est vulnérable) |
| Niveau Requis | 16 |
| Déblocage | Maîtrise Confirmé |

## Séquence d'Animation
Le joueur lance une poignée de projectiles qui se fragmentent en vol. Quatre éclats pleuvent sur la zone, touchant potentiellement plusieurs cibles.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Confirmé
- **Commande** : `!learn_skill OSS_JET_005` puis `!cast pluie_d_eclats` en combat

## Lore (Encyclopédie d'Argo)
Les artificiers de guerre ont inventé ce skill pour maximiser les dégâts de zone. Chaque projectile se brise en quatre éclats tranchants.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_JET_005')`
