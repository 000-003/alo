# Lame de l'Horizon

## Identification Cardinal
- **Skill_ID** : `OSS_JET_006`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Armes de Jet
- **Tier** : T3 · **Rareté** : Épique

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 44 |
| Coût Stamina | 44% de la jauge |
| Nombre de Hits | 5 |
| Multiplicateur Total | ×3.2 |
| Post-Motion Delay | 1.5s (le joueur est vulnérable) |
| Niveau Requis | 24 |
| Déblocage | Maîtrise Confirmé + Entraîneur |

## Séquence d'Animation
Le joueur lance cinq lames qui rasent l'horizon avant de remonter brusquement pour frapper la cible par en dessous. Trajectoire imprévisible.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Confirmé + Entraîneur
- **Commande** : `!learn_skill OSS_JET_006` puis `!cast lame_de_l_horizon` en combat

## Lore (Encyclopédie d'Argo)
Un skill de ninja avancé qui utilise la courbure de l'horizon pour dissimuler la trajectoire. Difficile à contrer.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_JET_006')`
