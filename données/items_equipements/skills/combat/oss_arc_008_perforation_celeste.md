# Perforation Céleste

## Identification Cardinal
- **Skill_ID** : `OSS_ARC_008`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Arc
- **Tier** : T3 · **Rareté** : Épique

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 46 |
| Coût Stamina | 46% de la jauge |
| Nombre de Hits | 6 |
| Multiplicateur Total | ×3.4 |
| Post-Motion Delay | 1.8s (le joueur est vulnérable) |
| Niveau Requis | 26 |
| Déblocage | Maîtrise Confirmé + Entraîneur |

## Séquence d'Animation
Le joueur tire six flèches lumineuses qui traversent tout sur leur passage. Chaque flèche gagne en puissance en perforant les ennemis successifs.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Confirmé + Entraîneur
- **Commande** : `!learn_skill OSS_ARC_008` puis `!cast perforation_celeste` en combat

## Lore (Encyclopédie d'Argo)
Un skill de pénétration redoutable. Les rangs ennemis ne sont plus une protection quand les flèches traversent les lignes.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_ARC_008')`
