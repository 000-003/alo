# Tourbillon de Couteaux

## Identification Cardinal
- **Skill_ID** : `OSS_JET_004`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Armes de Jet
- **Tier** : T2 · **Rareté** : Rare

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 20 |
| Coût Stamina | 26% de la jauge |
| Nombre de Hits | 3 |
| Multiplicateur Total | ×2.0 |
| Post-Motion Delay | 1.0s (le joueur est vulnérable) |
| Niveau Requis | 12 |
| Déblocage | Maîtrise Confirmé |

## Séquence d'Animation
Le joueur lance trois couteaux en rotation rapide, chacun décrivant une trajectoire courbe pour attaquer sous différents angles.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Confirmé
- **Commande** : `!learn_skill OSS_JET_004` puis `!cast tourbillon_de_couteaux` en combat

## Lore (Encyclopédie d'Argo)
Les artistes de cirque sont à l'origine de ce skill. Les couteaux tournoient comme dans un numéro de lancer, mais avec des conséquences moins divertissantes.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_JET_004')`
