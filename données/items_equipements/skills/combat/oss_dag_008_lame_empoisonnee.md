# Lame Empoisonnée

## Identification Cardinal
- **Skill_ID** : `OSS_DAG_008`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Dague
- **Tier** : T3 · **Rareté** : Épique

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 48 |
| Coût Stamina | 50% de la jauge |
| Nombre de Hits | 7 |
| Multiplicateur Total | ×3.6 |
| Post-Motion Delay | 2.0s (le joueur est vulnérable) |
| Niveau Requis | 30 |
| Déblocage | Maîtrise Confirmé + Entraîneur |

## Séquence d'Animation
La dague s'enduit d'un venin violet iridescent. Sept entailles rapides empoisonnent l'ennemi, empilant des dégâts sur la durée dévastateurs.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Confirmé + Entraîneur
- **Commande** : `!learn_skill OSS_DAG_008` puis `!cast lame_empoisonnee` en combat

## Lore (Encyclopédie d'Argo)
Les alchimistes de la Guilde des Poisons ont développé ce skill. Le venin est si corrosif qu'il peut désintégrer les armures métalliques.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_DAG_008')`
