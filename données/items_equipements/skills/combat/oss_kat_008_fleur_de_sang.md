# Fleur de Sang

## Identification Cardinal
- **Skill_ID** : `OSS_KAT_008`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Katana
- **Tier** : T3 · **Rareté** : Épique

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 50 |
| Coût Stamina | 50% de la jauge |
| Nombre de Hits | 7 |
| Multiplicateur Total | ×3.6 |
| Post-Motion Delay | 2.0s (le joueur est vulnérable) |
| Niveau Requis | 29 |
| Déblocage | Maîtrise Confirmé + Entraîneur |

## Séquence d'Animation
Le joueur s'immobilise, puis explose en sept entailles radiales formant une fleur écarlate autour de lui. Le sang des ennemis jaillit en forme de pétales.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Confirmé + Entraîneur
- **Commande** : `!learn_skill OSS_KAT_008` puis `!cast fleur_de_sang` en combat

## Lore (Encyclopédie d'Argo)
Le pratiquant doit verser une goutte de son propre sang pour débloquer ce skill. Un pacte sanglant avec le système.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_KAT_008')`
