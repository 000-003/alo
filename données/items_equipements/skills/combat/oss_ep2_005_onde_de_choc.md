# Onde de Choc

## Identification Cardinal
- **Skill_ID** : `OSS_EP2_005`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Épée 2M
- **Tier** : T2 · **Rareté** : Rare

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 25 |
| Coût Stamina | 32% de la jauge |
| Nombre de Hits | 3 |
| Multiplicateur Total | ×2.4 |
| Post-Motion Delay | 1.0s (le joueur est vulnérable) |
| Niveau Requis | 16 |
| Déblocage | Maîtrise Confirmé |

## Séquence d'Animation
Le joueur frappe le sol du plat de l'épée, libérant trois ondes de choc successives qui balayent le champ de bataille. Idéal pour le contrôle de foule.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Confirmé
- **Commande** : `!learn_skill OSS_EP2_005` puis `!cast onde_de_choc` en combat

## Lore (Encyclopédie d'Argo)
Un skill de zone enseigné par les gardes-frontières. Utile pour disperser les groupes d'ennemis avant de les affronter un par un.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_EP2_005')`
