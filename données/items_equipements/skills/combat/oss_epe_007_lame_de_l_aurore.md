# Lame de l'Aurore

## Identification Cardinal
- **Skill_ID** : `OSS_EPE_007`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Épée 1M
- **Tier** : T3 · **Rareté** : Épique

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 45 |
| Coût Stamina | 45% de la jauge |
| Nombre de Hits | 5 |
| Multiplicateur Total | ×3.2 |
| Post-Motion Delay | 1.5s (le joueur est vulnérable) |
| Niveau Requis | 22 |
| Déblocage | Maîtrise Confirmé + Entraîneur |

## Séquence d'Animation
Le joueur lève l'épée vers le ciel, captant une lumière dorée. Cinq frappes tombent en cascade, chacune plus brillante que la précédente, imitant les premiers rayons du soleil.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Confirmé + Entraîneur
- **Commande** : `!learn_skill OSS_EPE_007` puis `!cast lame_de_l_aurore` en combat

## Lore (Encyclopédie d'Argo)
Un skill enseigné par les moines-guerriers du Temple de l'Orient. Chaque frappe représente une heure du matin.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_EPE_007')`
