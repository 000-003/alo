# Estoc Précieux

## Identification Cardinal
- **Skill_ID** : `OSS_RAP_004`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Rapière
- **Tier** : T2 · **Rareté** : Rare

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 20 |
| Coût Stamina | 25% de la jauge |
| Nombre de Hits | 2 |
| Multiplicateur Total | ×2.0 |
| Post-Motion Delay | 1.0s (le joueur est vulnérable) |
| Niveau Requis | 12 |
| Déblocage | Maîtrise Confirmé |

## Séquence d'Animation
Un duo d'estocades précises : la première désarme l'ennemi, la seconde le transperce. Le mouvement est élégant, digne d'un maître escrimeur.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Confirmé
- **Commande** : `!learn_skill OSS_RAP_004` puis `!cast estoc_precieux` en combat

## Lore (Encyclopédie d'Argo)
Enseigné par la noblesse d'Aincrad, ce skill reflète l'art du duel raffiné. Pas de force brute, seulement la précision chirurgicale.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_RAP_004')`
