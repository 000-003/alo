# Flèche du Dragon

## Identification Cardinal
- **Skill_ID** : `OSS_LAN_008`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Lance
- **Tier** : T3 · **Rareté** : Épique

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 50 |
| Coût Stamina | 50% de la jauge |
| Nombre de Hits | 7 |
| Multiplicateur Total | ×3.6 |
| Post-Motion Delay | 2.0s (le joueur est vulnérable) |
| Niveau Requis | 30 |
| Déblocage | Maîtrise Confirmé + Entraîneur |

## Séquence d'Animation
Le joueur lance sa lance comme un javelot d'énergie draconique. La lance se multiplie en sept projectiles qui pleuvent sur la cible.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Confirmé + Entraîneur
- **Commande** : `!learn_skill OSS_LAN_008` puis `!cast fleche_du_dragon` en combat

## Lore (Encyclopédie d'Argo)
Les chasseurs de dragons ont perfectionné ce skill pour abattre les Wyvernes en vol. Elle fonctionne aussi sur les boss volants.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_LAN_008')`
