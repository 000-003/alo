# Flèche de Lumière

## Identification Cardinal
- **Skill_ID** : `OSS_ARC_010`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Arc
- **Tier** : T4 · **Rareté** : Légendaire

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 80 |
| Coût Stamina | 62% de la jauge |
| Nombre de Hits | 8 |
| Multiplicateur Total | ×5.0 |
| Post-Motion Delay | 2.5s (le joueur est vulnérable) |
| Niveau Requis | 35 |
| Déblocage | Maîtrise Avancé + Quête « Le Rayon Pur » |

## Séquence d'Animation
Le joueur bande son arc et une flèche de pure lumière se matérialise. Huit rayons lumineux transpercent l'ennemi, infligeant des dégâts sacrés.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Avancé + Quête « Le Rayon Pur »
- **Commande** : `!learn_skill OSS_ARC_010` puis `!cast fleche_de_lumiere` en combat

## Lore (Encyclopédie d'Argo)
Un don des Anges de Lumière. Les PNG démons fuient à la simple vue de ce skill. Très efficace dans les donjons maudits.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_ARC_010')`
