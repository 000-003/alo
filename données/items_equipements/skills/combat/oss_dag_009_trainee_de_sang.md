# Traînée de Sang

## Identification Cardinal
- **Skill_ID** : `OSS_DAG_009`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Dague
- **Tier** : T4 · **Rareté** : Légendaire

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 78 |
| Coût Stamina | 62% de la jauge |
| Nombre de Hits | 8 |
| Multiplicateur Total | ×5.0 |
| Post-Motion Delay | 2.5s (le joueur est vulnérable) |
| Niveau Requis | 36 |
| Déblocage | Maîtrise Avancé + Quête « Le Festin des Corbeaux » |

## Séquence d'Animation
Le joueur trace une ligne sanglante en se déplaçant d'une cible à l'autre, portant huit attaques dont chacune laisse une plaie ouverte qui saigne abondamment.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Avancé + Quête « Le Festin des Corbeaux »
- **Commande** : `!learn_skill OSS_DAG_009` puis `!cast trainee_de_sang` en combat

## Lore (Encyclopédie d'Argo)
Un skill de chasseur de prime. Marquer sa proie d'une traînée écarlate permet de la traquer même si elle fuit le combat.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_DAG_009')`
