# Vent du Nord

## Identification Cardinal
- **Skill_ID** : `OSS_ARC_007`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Arc
- **Tier** : T3 · **Rareté** : Épique

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 42 |
| Coût Stamina | 42% de la jauge |
| Nombre de Hits | 5 |
| Multiplicateur Total | ×3.0 |
| Post-Motion Delay | 1.5s (le joueur est vulnérable) |
| Niveau Requis | 22 |
| Déblocage | Maîtrise Confirmé + Entraîneur |

## Séquence d'Animation
Cinq flèches portées par le vent du nord traversent le champ de bataille en tournoyant. Chaque flèche est glaciale, ralentissant la cible à l'impact.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Confirmé + Entraîneur
- **Commande** : `!learn_skill OSS_ARC_007` puis `!cast vent_du_nord` en combat

## Lore (Encyclopédie d'Argo)
Un skill enseigné par les chasseurs du Grand Nord. Les flèches glacées sont parfaites pour ralentir les ennemis rapides.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_ARC_007')`
