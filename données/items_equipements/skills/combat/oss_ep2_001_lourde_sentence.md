# Lourde Sentence

## Identification Cardinal
- **Skill_ID** : `OSS_EP2_001`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Épée 2M
- **Tier** : T5 · **Rareté** : Divin

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 140 |
| Coût Stamina | 80% de la jauge |
| Nombre de Hits | 12 |
| Multiplicateur Total | ×7.0 |
| Post-Motion Delay | 3.5s (le joueur est vulnérable) |
| Niveau Requis | 52 |
| Déblocage | Maîtrise Avancé + Quête Spéciale « Le Poids du Ciel » |

## Séquence d'Animation
Le joueur charge une énergie noire dans son épée, puis abat douze coups écrasants qui fissurent le sol. Le dernier coup provoque une onde de choc dévastatrice.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Avancé + Quête Spéciale « Le Poids du Ciel »
- **Commande** : `!learn_skill OSS_EP2_001` puis `!cast lourde_sentence` en combat

## Lore (Encyclopédie d'Argo)
On raconte que cette technique peut briser les défenses impénétrables des golems de Titan. Chaque coup porte le poids d'une montagne.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_EP2_001')`
