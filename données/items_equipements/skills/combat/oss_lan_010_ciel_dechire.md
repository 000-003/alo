# Ciel Déchiré

## Identification Cardinal
- **Skill_ID** : `OSS_LAN_010`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Lance
- **Tier** : T4 · **Rareté** : Légendaire

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 88 |
| Coût Stamina | 68% de la jauge |
| Nombre de Hits | 10 |
| Multiplicateur Total | ×5.8 |
| Post-Motion Delay | 3.0s (le joueur est vulnérable) |
| Niveau Requis | 44 |
| Déblocage | Maîtrise Avancé + Quête « La Fissure Céleste » |

## Séquence d'Animation
Le joueur bondit dans les airs et déchire le ciel de dix coups verticaux. Les entailles laissent des cicatrices lumineuses dans l'atmosphère.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Avancé + Quête « La Fissure Céleste »
- **Commande** : `!learn_skill OSS_LAN_010` puis `!cast ciel_dechire` en combat

## Lore (Encyclopédie d'Argo)
Les sages disent que ce skill peut briser le firmament. Des rumeurs parlent d'un joueur qui aurait ouvert un portail vers un étage secret avec ce skill.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_LAN_010')`
