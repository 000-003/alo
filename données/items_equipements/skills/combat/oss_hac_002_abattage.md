# Abattage

## Identification Cardinal
- **Skill_ID** : `OSS_HAC_002`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Hache
- **Tier** : T1 · **Rareté** : Commun

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 10 |
| Coût Stamina | 15% de la jauge |
| Nombre de Hits | 1 |
| Multiplicateur Total | ×1.3 |
| Post-Motion Delay | 0.5s (le joueur est vulnérable) |
| Niveau Requis | 3 |
| Déblocage | Maîtrise Novice |

## Séquence d'Animation
Un coup descendant puissant, comme si le joueur abattait un arbre. La hache décrit un arc large et s'écrase sur l'ennemi avec un bruit sourd.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Novice
- **Commande** : `!learn_skill OSS_HAC_002` puis `!cast abattage` en combat

## Lore (Encyclopédie d'Argo)
Les bûcherons du monde virtuel ont exporté leurs techniques de coupe dans le combat. Un skill efficace pour les débutants costauds.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_HAC_002')`
