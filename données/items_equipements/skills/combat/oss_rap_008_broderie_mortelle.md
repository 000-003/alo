# Broderie Mortelle

## Identification Cardinal
- **Skill_ID** : `OSS_RAP_008`
- **Catégorie** : Original Sword Skill (OSS)
- **Type d'Arme** : Rapière
- **Tier** : T3 · **Rareté** : Épique

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 50 |
| Coût Stamina | 50% de la jauge |
| Nombre de Hits | 7 |
| Multiplicateur Total | ×3.6 |
| Post-Motion Delay | 2.0s (le joueur est vulnérable) |
| Niveau Requis | 30 |
| Déblocage | Maîtrise Confirmé + Entraîneur |

## Séquence d'Animation
Le joueur brode une toile de coups autour de l'ennemi, sept estocades en étoile qui couturent l'air de fil de lumière. La dernière perce le point faible identifié.

## Effet Spécial
Les OSS ignorent **15% de la DEF** ennemie. Perfect Chain +20%.

## Acquisition (Maîtrise d'arme)
- **Déblocage** : Maîtrise Confirmé + Entraîneur
- **Commande** : `!learn_skill OSS_RAP_008` puis `!cast broderie_mortelle` en combat

## Lore (Encyclopédie d'Argo)
Une technique transmise par la Guilde des Tailleurs de Lumière. Oui, des tailleurs. Leur précision avec une aiguille est légendaire.

## Commande IA
- `SYS_GRANT_OSS(Avatar_ID, 'OSS_RAP_008')`
