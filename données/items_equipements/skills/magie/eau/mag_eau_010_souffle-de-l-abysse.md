# Souffle de l'Abysse

## Identification Cardinal
- **Skill_ID** : `MAG_EAU_010`
- **Catégorie** : Magie — Eau
- **Tier** : T5 · **Rareté** : Légendaire
- **Race Affinité** : Undine (+30% efficacité si cette race)

## Paramètres de Combat
| Paramètre | Valeur |
|---|---|
| Coût MP | 550 |
| Temps d'Incantation | 5.0s |
| Cooldown | 1/combat |
| Niveau Requis | 43 |
| Interruptible (Casting Break) | Oui (si dégâts > 5% Max HP reçus) |

## Effet
Souffle de l'Abysse : pression des profondeurs écrasant tous les ennemis.
**Zone d'effet** : Oui

## Incantation
*Le joueur tape `!cast souffle-de-l-abysse` pour lancer le sort.*

## Acquisition (Quête Spéciale)
- **Déblocage** : Quête exclusive (jamais enseigné en boutique)
- **Prix d'apprentissage** : Non applicable
- **Commande** : `!learn_skill MAG_EAU_010`

## Lore (Encyclopédie d'Argo)
