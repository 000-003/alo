# Potion de Soin (Grade C)

## Identification Cardinal
- **Item_ID** : `CSM_POT_HP_C`
- **Type** : Consommable — Potion
- **Tier** : T1
- **Stackable** : Oui (max 99)

## Effet
Restaure 200 HP instantanément.

## Durée
Instantané

## Économie
- **Prix Marchand** : 50 Yrds
- **Recette d'Alchimie** : 1x Herbe Médicinale + 1x Eau Purifiée

Le consommable le plus basique d'ALfheim. Chaque aventurier en garde une dizaine sur lui en permanence. Son goût est décrit comme 'de l'eau avec un arrière-goût de menthe numérique'.
