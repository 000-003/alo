# Antidote Universel

## Identification Cardinal
- **Item_ID** : `CSM_POT_ANT`
- **Type** : Consommable — Potion
- **Tier** : T2
- **Stackable** : Oui (max 99)

## Effet
Supprime tous les statuts négatifs (Poison, Paralysie, Brûlure, Cécité).

## Durée
Instantané

## Économie
- **Prix Marchand** : 300 Yrds
- **Recette d'Alchimie** : 1x Herbe Antidote + 1x Venin de Serpent Purifié

## Lore
Un liquide verdâtre au goût amer. Les aventuriers expérimentés n'entrent jamais dans les marais de Jötunheimr sans une réserve d'antidotes.
