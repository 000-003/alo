# Lame de Jugement

## Identification Cardinal
- **Item_ID** : `WPN_S2H_005`
- **Type** : Épée à deux mains
- **Tier** : T4 (Niveau recommandé : 61-80)
- **Rareté** : Légendaire

## Statistiques de Combat
| Paramètre | Valeur |
|---|---|
| ATK de Base | 250 |
| Vitesse d'Attaque | Lente (1.8s) |
| Modificateur Critique | x2.8 |
| Poids (kg) | 8.0 |
| Affinité Élémentaire | Lumière |
| Durabilité Max | 450 |

## Prérequis
- **STR min** : 130 | **DEX min** : 25 | **Niveau min** : 61

## Économie
- **Achat** : 45000 Yrds | **Revente** : 18000 Yrds | **Réparation** : 4500 Yrds
- **Source** : Récompense unique : Raid du Palier 95 (First Clear Bonus)

## Capacité Spéciale
Chaque ennemi tué par cette lame accorde un stack permanent de +2 ATK (max 50 stacks = +100 ATK). Les stacks se réinitialisent si le joueur meurt.

## Lore (Encyclopédie d'Argo)
La légende dit que cette lame pèse les âmes des monstres qu'elle abat. Plus son porteur combat le mal, plus elle devient puissante. Mais la mort efface le jugement et l'épée redevient vierge.
