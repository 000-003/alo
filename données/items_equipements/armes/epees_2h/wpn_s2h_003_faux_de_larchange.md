# Faux de l'Archange

## Identification Cardinal
- **Item_ID** : `WPN_S2H_003`
- **Type** : Épée à deux mains
- **Tier** : T3 (Niveau recommandé : 41-60)
- **Rareté** : Épique

## Statistiques de Combat
| Paramètre | Valeur |
|---|---|
| ATK de Base | 210 |
| Vitesse d'Attaque | Très Lente (2.5s) |
| Modificateur Critique | x3.0 |
| Poids (kg) | 10.0 |
| Portée | Mêlée |
| Affinité Élémentaire | Lumière |
| Durabilité Max | 350 |
| Coût de Réparation | 2200 Yrds |

## Prérequis d'Équipement
- **STR minimum** : 120
- **DEX minimum** : 15
- **Niveau minimum** : 41

## Économie
- **Prix Marchand (Achat)** : 22000 Yrds
- **Prix de Revente** : 8800 Yrds
- **Source de Drop** : Drop Boss Palier 65 de New Aincrad (3%)
- **Taux de Drop** : 15%

## Capacité Spéciale
On dit que le Système Cardinal s'est inspiré des fresques du 65e Palier pour générer cette arme : une lame si large qu'elle projette une ombre en forme d'aile d'ange. Le joueur qui la brandit ne peut plus voler tant elle est lourde.

## Lore (Encyclopédie d'Argo)
Les attaques chargées (2 tours de préparation) infligent x4 dégâts au lieu de x2.5 pour les critiques.

## Commande IA Associée
- `SYS_DROP_WEAPON(Avatar_ID, "WPN_S2H_003")` : L'IA peut forcer le drop de cette arme en récompense narrative.
- `SYS_BREAK_WEAPON("WPN_S2H_003", Instance_ID)` : L'IA peut briser cette arme en combat pour créer du drame.
