# Épée Longue en Fer

## Identification Cardinal
- **Item_ID** : `WPN_S1H_001`
- **Type** : Épée à une main
- **Tier** : T1 (Niveau recommandé : 1-20)
- **Rareté** : Commune

## Statistiques de Combat
| Paramètre | Valeur |
|---|---|
| ATK de Base | 45 |
| Vitesse d'Attaque | Moyenne (1.2s) |
| Modificateur Critique | x1.8 |
| Poids (kg) | 3.5 |
| Portée | Mêlée |
| Affinité Élémentaire | Aucun |
| Durabilité Max | 200 |
| Coût de Réparation | 80 Yrds |

## Prérequis d'Équipement
- **STR minimum** : 20
- **DEX minimum** : 10
- **Niveau minimum** : 1

## Économie
- **Prix Marchand (Achat)** : 800 Yrds
- **Prix de Revente** : 320 Yrds
- **Source de Drop** : Forgeron de départ (toutes capitales)
- **Taux de Drop** : 25%

## Capacité Spéciale
La première arme que tout aventurier d'ALfheim reçoit en quittant sa capitale. Forgée dans le fer brut des mines Gnomes, son tranchant est modeste mais honnête. Les Leprechauns la considèrent comme un exercice d'apprenti.

## Lore (Encyclopédie d'Argo)
Aucune capacité spéciale. Arme basique mais fiable.

## Commande IA Associée
- `SYS_DROP_WEAPON(Avatar_ID, "WPN_S1H_001")` : L'IA peut forcer le drop de cette arme en récompense narrative.
- `SYS_BREAK_WEAPON("WPN_S1H_001", Instance_ID)` : L'IA peut briser cette arme en combat pour créer du drame.
