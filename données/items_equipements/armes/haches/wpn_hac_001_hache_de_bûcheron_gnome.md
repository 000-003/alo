# Hache de Bûcheron Gnome

## Identification Cardinal
- **Item_ID** : `WPN_HAC_001`
- **Type** : Hache à une main
- **Tier** : T1 (Niveau recommandé : 1-20)
- **Rareté** : Commune

## Statistiques de Combat
| Paramètre | Valeur |
|---|---|
| ATK de Base | 60 |
| Vitesse d'Attaque | Lente (1.6s) |
| Modificateur Critique | x1.8 |
| Poids (kg) | 5.5 |
| Portée | Mêlée |
| Affinité Élémentaire | Terre |
| Durabilité Max | 240 |
| Coût de Réparation | 100 Yrds |

## Prérequis d'Équipement
- **STR minimum** : 35
- **DEX minimum** : 5
- **Niveau minimum** : 1

## Économie
- **Prix Marchand (Achat)** : 1000 Yrds
- **Prix de Revente** : 400 Yrds
- **Source de Drop** : Marchands Gnomes
- **Taux de Drop** : 25%

## Capacité Spéciale
Les Gnomes ne distinguent pas l'outil de l'arme. Cette hache sert aussi bien à creuser les tunnels qu'à fendre les crânes des envahisseurs.

## Lore (Encyclopédie d'Argo)
Peut abattre les arbres pour récolter du bois de craft.

## Commande IA Associée
- `SYS_DROP_WEAPON(Avatar_ID, "WPN_HAC_001")` : L'IA peut forcer le drop de cette arme en récompense narrative.
- `SYS_BREAK_WEAPON("WPN_HAC_001", Instance_ID)` : L'IA peut briser cette arme en combat pour créer du drame.
