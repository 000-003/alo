# Dague d'Assassin

## Identification Cardinal
- **Item_ID** : `WPN_DAG_001`
- **Type** : Dague
- **Tier** : T1 (Niveau recommandé : 1-20)
- **Rareté** : Commune

## Statistiques de Combat
| Paramètre | Valeur |
|---|---|
| ATK de Base | 30 |
| Vitesse d'Attaque | Très Rapide (0.4s) |
| Modificateur Critique | x3.0 |
| Poids (kg) | 1.0 |
| Portée | Mêlée |
| Affinité Élémentaire | Aucun |
| Durabilité Max | 150 |
| Coût de Réparation | 60 Yrds |

## Prérequis d'Équipement
- **STR minimum** : 5
- **DEX minimum** : 25
- **Niveau minimum** : 1

## Économie
- **Prix Marchand (Achat)** : 600 Yrds
- **Prix de Revente** : 240 Yrds
- **Source de Drop** : Marchands de toutes les capitales
- **Taux de Drop** : 25%

## Capacité Spéciale
Fine comme un ongle de fée, cette dague est l'arme de prédilection des Imps et des assassins de toutes races. Son faible ATK est compensé par la fréquence de ses frappes.

## Lore (Encyclopédie d'Argo)
Double le taux de critique lorsque le joueur attaque depuis la furtivité (!hide).

## Commande IA Associée
- `SYS_DROP_WEAPON(Avatar_ID, "WPN_DAG_001")` : L'IA peut forcer le drop de cette arme en récompense narrative.
- `SYS_BREAK_WEAPON("WPN_DAG_001", Instance_ID)` : L'IA peut briser cette arme en combat pour créer du drame.
