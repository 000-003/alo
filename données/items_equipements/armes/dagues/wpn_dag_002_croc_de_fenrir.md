# Croc de Fenrir

## Identification Cardinal
- **Item_ID** : `WPN_DAG_002`
- **Type** : Dague
- **Tier** : T2 (Niveau recommandé : 21-40)
- **Rareté** : Rare

## Statistiques de Combat
| Paramètre | Valeur |
|---|---|
| ATK de Base | 55 |
| Vitesse d'Attaque | Très Rapide (0.4s) |
| Modificateur Critique | x3.5 |
| Poids (kg) | 1.2 |
| Portée | Mêlée |
| Affinité Élémentaire | Glace |
| Durabilité Max | 200 |
| Coût de Réparation | 350 Yrds |

## Prérequis d'Équipement
- **STR minimum** : 10
- **DEX minimum** : 40
- **Niveau minimum** : 21

## Économie
- **Prix Marchand (Achat)** : 3500 Yrds
- **Prix de Revente** : 1400 Yrds
- **Source de Drop** : Drop Loup Fenrir dans les Plaines Gelées (7%)
- **Taux de Drop** : 20%

## Capacité Spéciale
Taillée dans le croc d'un descendant de Fenrir, la dague est toujours froide au toucher. Les chasseurs Cait Sith la considèrent comme le trophée ultime d'une chasse hivernale.

## Lore (Encyclopédie d'Argo)
Applique [Paralysie] pendant 1 tour si le coup est un critique (25% de chance avec DEX > 200).

## Commande IA Associée
- `SYS_DROP_WEAPON(Avatar_ID, "WPN_DAG_002")` : L'IA peut forcer le drop de cette arme en récompense narrative.
- `SYS_BREAK_WEAPON("WPN_DAG_002", Instance_ID)` : L'IA peut briser cette arme en combat pour créer du drame.
