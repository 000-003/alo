# Rapière d'Entraînement

## Identification Cardinal
- **Item_ID** : `WPN_RAP_001`
- **Type** : Rapière
- **Tier** : T1 (Niveau recommandé : 1-20)
- **Rareté** : Commune

## Statistiques de Combat
| Paramètre | Valeur |
|---|---|
| ATK de Base | 38 |
| Vitesse d'Attaque | Très Rapide (0.5s) |
| Modificateur Critique | x2.5 |
| Poids (kg) | 1.5 |
| Portée | Mêlée |
| Affinité Élémentaire | Aucun |
| Durabilité Max | 180 |
| Coût de Réparation | 70 Yrds |

## Prérequis d'Équipement
- **STR minimum** : 10
- **DEX minimum** : 30
- **Niveau minimum** : 1

## Économie
- **Prix Marchand (Achat)** : 700 Yrds
- **Prix de Revente** : 280 Yrds
- **Source de Drop** : Forgeron de toutes les capitales
- **Taux de Drop** : 25%

## Capacité Spéciale
Fine comme une aiguille, la rapière est l'arme de prédilection des duellistes Undines. Asuna Yuuki, la Berserk Healer, a élevé cet art au rang de légende.

## Lore (Encyclopédie d'Argo)
Hit count élevé : chaque attaque frappe 2 fois (multi-hit).

## Commande IA Associée
- `SYS_DROP_WEAPON(Avatar_ID, "WPN_RAP_001")` : L'IA peut forcer le drop de cette arme en récompense narrative.
- `SYS_BREAK_WEAPON("WPN_RAP_001", Instance_ID)` : L'IA peut briser cette arme en combat pour créer du drame.
