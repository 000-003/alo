## 🧩 Pièces d'Armure (Slots)

Chaque set d'armure se compose de **5 pièces** avec les multiplicateurs suivants :

| Slot | % de la DEF Totale | % de la MDEF Totale | Poids Relatif |
|:---|---:|---:|---:|
| **Casque** | 18% | 15% | 15% |
| **Plastron** | 35% | 30% | 35% |
| **Gantelets** | 12% | 15% | 12% |
| **Jambières** | 22% | 20% | 23% |
| **Bottes** | 13% | 20% | 15% |

> **Exemple** : Une Plaque T3 (DEF 120 totale) donnerait :
> - Casque : 22 DEF | Plastron : 42 DEF | Gantelets : 14 DEF | Jambières : 26 DEF | Bottes : 16 DEF

## 🎁 Bonus de Set Complet

Porter les 5 pièces du même type et du même tier accorde un bonus :

| Type | Bonus Set 3/5 pièces | Bonus Set 5/5 pièces |
