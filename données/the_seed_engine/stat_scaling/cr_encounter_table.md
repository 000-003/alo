## 🧮 Formule de Calcul du CR

```
CR_Mob = (HP / 100) + (ATK × 2) + (DEF × 1.5) + (MDEF × 1.0)
CR_Rencontre = Σ CR_Mobs × Facteur_Synergie

Facteur_Synergie :
- Mobs seuls : ×1.0
- 2 mobs même type : ×1.1
- 3+ mobs même type : ×1.3
- Mobs + Élite : ×1.5
- Mobs + Mini-Boss : ×2.0

Difficulté Recommandée (groupe de 4) :
- Facile : CR_Rencontre < CR_Groupe × 0.6
- Modérée : CR_Rencontre ≈ CR_Groupe × 0.8-1.0
- Difficile : CR_Rencontre ≈ CR_Groupe × 1.2-1.5
- Extrême : CR_Rencontre > CR_Groupe × 1.8
```
